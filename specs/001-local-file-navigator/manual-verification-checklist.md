## FR-040: 200% 文本缩放验证

**验收条件**: 200% 缩放下 UJ-1~UJ-4 无文字裁切、控件遮挡或功能丢失

1. 系统设置 → 显示 → 缩放与布局 → 200%

|---|--------|------|

| 2 | 类别名无裁切（可访问名称为完整名称） | ☐ |
| 3 | 卡片名无裁切 | ☐ |

| 6 | 模态框内容可滚动 + 操作区可达 | ☐ |
| 7 | 搜索框无裁切 | ☐ |
| 8 | 工具按钮无裁切 | ☐ |
| 9 | status-bar 不遮挡卡片 | ☐ |
