# Quickstart: 本地文件导航工具

**Feature**: 001-local-file-navigator
**Date**: 2026-07-22

> 本文档定义可运行的验证场景和预期结果，供开发完成后逐项验证。
> 具体实现代码见 `tasks.md`（由 `/speckit-tasks` 生成）。

## Prerequisites

- Node.js 20 LTS+
- npm 10+
- Windows 10+ 或 macOS 12+
- Git

## Setup

```bash
git clone <repo-url>
cd <project-root>
npm install
```

## Run (Development)

```bash
npm run dev        # 启动 Electron + Vite dev server
```

## E2E Validation Scenarios

### VS-1: 首次收录文件 (UJ-1)

1. `npm run dev` 启动应用
2. 确认左侧栏仅显示"全部卡片"
3. 确认主区显示 "添加常用文件。应用不会扫描磁盘。"
4. 点击"选择文件" → 选择一个 .html 文件
5. 确认模态框名称预填为页面标题
6. 创建新类别 → 确认自动选中
7. 点击"保存"
8. **Expect**: 卡片出现在全部卡片网格中，显示名称、类型标记和类别标签
9. 关闭窗口
10. **Expect**: 应用主进程及全部 Electron 子进程退出

### VS-2: 快速打开文件 (UJ-2)

1. (预置数据: 至少 3 张卡片)
2. 启动应用 → 确认进入"全部卡片"
3. 点击任意卡片主体
4. **Expect**: 文件由默认应用打开
5. 切换到一个用户类别 → 确认只显示该类别的卡片
6. 在搜索框输入卡片名称片段
7. **Expect**: 实时筛选结果，每次仅播报结果数（不播报每张卡片内容），左侧类别不变
8. 清空搜索 → 确认恢复原类别视图

### VS-3: 整理分类与排序 (UJ-3)

1. (预置: 3 个类别，每个含 2-5 张卡片，至少 1 张卡片属于 2 个类别)
2. 进入用户类别 → 点击"整理排序"
3. 将第 3 张卡片上移 2 位 → **Expect**: 立即生效，播报"第 1/5 张"
4. 退出整理 → 切换到另一含此卡片的类别 → **Expect**: 位置未变（独立顺序）
5. 创建新类别"工作" → **Expect**: 出现在用户类别区
6. 重命名"工作"为"办公" → **Expect**: 名称更新
7. 删除空类别 → 确认对话框显示卡片数 → 确认删除

### VS-4: 修复失败文件 (UJ-4)

1. (预置: 一张卡片指向存在但将被重命名的文件)
2. 在系统中重命名该源文件
3. 回到应用，点击该卡片
4. **Expect**: 显示"无法打开文件。卡片仍被保留。"对话框
5. 选择"重新选择文件" → 通过文件选择器选取原文件的新名称
6. **Expect**: 对话框关闭，status-bar 显示"已重新关联"，卡片数据不变
7. 在文件管理器中重命名源文件
8. 点击卡片"在文件管理器中显示" → **Expect**: S17 定位失败对话框，可重新选择

### VS-5: 单实例与退出生命周期

1. 应用运行中 → 关闭窗口
2. **Expect**: 窗口关闭，主进程、Renderer、GPU、Utility 进程全部退出
3. 重新启动应用，再次双击同一 EXE
4. **Expect**: 不创建第二组进程，已有窗口恢复、显示并获得焦点
5. 重新启动 → **Expect**: 进入"全部卡片"（冷启动）

### VS-6: 数据持久化

1. 创建 2 张卡片、1 个类别
2. 关闭窗口退出应用
3. 重启应用
4. **Expect**: 卡片和类别完整恢复
5. 系统重启后再次打开 → **Expect**: 同上

### VS-7: 无障碍键盘导航

1. 启动应用 → Tab 键遍历
2. **Expect**: Tab 顺序为 类别导航 → 搜索框 → 工具按钮 → 卡片网格
3. Enter 打开卡片，Esc 关闭对话框/清空搜索
4. 方向键切换类别项和菜单项
5. **Expect**: 所有功能无需鼠标完成，焦点外环始终可见

### VS-8: 200% 缩放与最小窗口

1. 系统设置 200% 文本缩放
2. 调整窗口到约 760×560
3. **Expect**: 卡片降至一列，所有文字完整可见
4. 打开新增模态框 → 内容可滚动，操作区可达
5. 恢复常规窗口 → **Expect**: 恢复多列网格
