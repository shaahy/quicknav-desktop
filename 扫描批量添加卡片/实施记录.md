# 扫描批量添加卡片实施记录

## 已确认范围

- 扫描所选文件夹及全部子文件夹。
- 支持多选类型：HTML、Word、PowerPoint、Excel、Markdown。
- 扫描结果逐行编辑卡片名称和多个类别。
- 支持将一组类别一次应用到全部待添加项。
- 校验通过后一次性批量保存。

## 实施基线

- 当前工作树在本任务开始前已有未提交修改；本任务不回退、不覆盖无关改动。
- 当前数据模型使用相对于 `app-data.json` 目录的文件路径，因此扫描目录须位于同一磁盘。
- 当前卡片上限为 500，卡片名称要求全局唯一，每张新卡片至少属于一个用户类别。

## 状态

实施完成，自动化验证通过。

## 已实现

### 扫描入口与界面

- 顶部工具栏增加“扫描”按钮；有卡片时排列为“新建卡片 → 整理排序 → 扫描”，无卡片时排列为“新建卡片 → 扫描”。
- 扫描界面支持选择文件夹、递归扫描、多选文件类型。
- 支持类型：
  - HTML：`html`、`htm`
  - Word：`doc`、`docx`
  - PowerPoint：`ppt`、`pptx`
  - Excel：`xls`、`xlsx`
  - Markdown：`md`
- HTML 默认卡片名优先使用 `<title>`，其他文件使用不带扩展名的文件名。
- 扫描结果按列表展示文件名、相对路径、卡片名和类别。
- 支持逐行修改名称、逐行多选类别、统一应用类别、移除不需要的行。

### 扫描与异常处理

- Main 进程执行递归扫描，不跟随符号链接，避免目录循环。
- 无法访问的目录或文件不会中断整个扫描，界面汇总跳过数量。
- 已存在的文件路径自动从待添加列表排除并显示数量。
- 所选目录与数据目录跨磁盘时给出明确提示。

### 批量添加

- 新增真正的批量添加路径，不循环调用单卡 `addCard()`。
- 保存前校验：
  - 名称非空、单行、不超过 80 字符。
  - 名称不与现有卡片或本批次其他卡片重复。
  - 文件路径不与现有卡片或本批次其他卡片重复。
  - 每张卡片至少选择一个有效用户类别。
  - 添加后总数不超过 500。
- 一次构造全部卡片和相关视图顺序，只调用一次 `saveAppData()`。
- 保存成功后才更新 Renderer 状态；保存失败时保留扫描界面和编辑内容。

## 主要代码

- `src/main/shell.ts`：目录选择、递归扫描、类型过滤、HTML 标题读取。
- `src/main/ipc.ts`、`src/preload/index.ts`：扫描 IPC 与 Renderer 桥接。
- `src/shared/types.ts`、`src/shared/constants.ts`：扫描与批量添加契约。
- `src/renderer/hooks/useCards.ts`：批量校验、单次保存。
- `src/renderer/contexts/AppState.tsx`：批量状态更新。
- `src/renderer/components/scan-dialog.tsx`：扫描和批量编辑界面。
- `src/renderer/styles/components/scan-dialog.css`：扫描界面样式。
- `src/renderer/components/app-shell.tsx`：顶部入口和流程编排。
