topic: 本地 HTML 技能速查导航工具
goal: 把分散在本地各磁盘的静态 HTML 技能速查入口集中管理，显著降低寻找、记忆路径与打开文件的日常成本
mode: partner
updated: 2026-07-21T16:56
---

- (direction by user) 已有一系列散落在本机不同目录和磁盘的静态 HTML 技能速查，寻找文件、记忆位置和逐个打开是高频时间损耗。
- (idea by user) 制作一个本地自用导航应用，以可配置卡片集中管理 HTML 路径，点击卡片后使用默认浏览器打开对应文件。
- (decision by user) 脑暴采用 Creative Partner 模式，技术批次由引导者根据目标选择。
- (technique by coach) started Job to Be Done
- (idea by coach) 这个工具的底层任务可能不是管理 HTML 路径，而是让用户无需回忆资料存放位置、无需离开当前思路，就能立即恢复所需框架知识。
- (direction by user) 无需继续追问使用场景：问题就是本地 HTML 文件分散、难以找到，造成时间浪费并直接影响工作效率。
- (insight by coach) 核心任务已明确：不依赖记忆物理路径，以最低操作成本定位并打开任意技能速查 HTML。
- (technique by coach) started Assumption Reversal
- (idea by coach) 反转“每张卡片都必须手工配置路径”的前提：应用可扫描用户指定的磁盘或根目录，自动发现 HTML、读取标题并生成候选卡片。
- (decision by user) 禁止自动扫描磁盘或目录，避免产生大量不需要的 HTML；所有卡片均由用户主动选择并手动配置路径。
- (idea by coach) “手动配置”不必等于手工键入路径：用户可通过文件选择器或拖放指定 HTML，由应用读取绝对路径并生成待编辑卡片，同时保留完全人工收录的边界。
- (decision by user) 新增卡片时通过系统文件选择器选择 HTML，不使用自动扫描。
- (idea by user) 类别是可由用户自行创建的一级对象；每张卡片归属于类别，首页按类别分类展示与管理，以提升查找效率和使用体验。
- (idea by coach) 类别可承担首页分区、手动排序、折叠展开和卡片数量提示，使首页既是导航面板也是轻量管理界面。
- (idea by user) 一张卡片可以同时归属于多个类别，并在每个所属类别下展示；卡片展示页支持快速手动切换当前类别。
- (direction by user) 应用仅供个人本地使用，以方便为最高优先级，但需要同时支持一台 Windows 电脑和一台 Mac。
- (idea by coach) 推荐产品形态为 Tauri 2 跨平台本地桌面应用：同一套前端支持 Windows 与 macOS，通过原生文件选择器收录 HTML，并调用系统默认应用打开路径。
- (insight by coach) 跨设备时应拆分共享的卡片目录元数据与设备专属路径映射；Windows 和 macOS 的绝对路径不能作为同一份配置直接复用。
- (direction by user) 用户认为 Tauri 方案可能过于复杂，更关心最终能否产出 Windows 可直接运行的 exe 与 macOS 应用，并偏好常规框架或语言。
- (insight by coach) Tauri 的复杂性主要在开发工具链，最终仍是 Windows setup.exe/MSI 与 macOS app/DMG，可像普通桌面软件双击使用。
- (idea by coach) 若开发简单和技术熟悉度优先于安装体积，可改用 Electron + 原生 HTML/CSS/JavaScript；同一代码库分别打包 Windows 可执行程序与 macOS app/DMG。
- (question by coach) 待确认是否将默认技术方向从 Tauri 调整为 Electron + 原生 HTML/CSS/JavaScript。
