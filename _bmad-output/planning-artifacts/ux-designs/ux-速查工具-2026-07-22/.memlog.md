- (decision) Discovery 来源范围确认：只采用最终 PRD、产品补充说明和最终审查报告；脑暴对账与结构/文案润色过程文件不作为 UX 输入。
- (decision) 首页信息架构采用固定左侧类别栏：全部卡片固定顶部，用户自建类别位于中部，未分类在存在卡片时固定底部；右侧为单一当前类别卡片主展示区，切换类别不进入新页面。
- (event) 已完成三份最终上游文档的 UX 事实提取，证据文件为 .working/source-extract-final-prd.md；未新增需求或 Architecture 决策。
- (decision) 卡片核心交互采用整张卡片主体单击执行主打开，卡片上常驻独立“更多”按钮；更多菜单承载编辑、在文件管理器中显示、移出当前类别和删除等管理动作，按钮与卡片主体为分离的点击及焦点目标，操作菜单不得触发打开。
- (decision) 卡片手动排序采用显式“整理排序”模式：进入后仅当前视图的卡片主体停止主打开并显示拖动手柄；拖动结果即时持久化且只改变当前视图顺序；退出后恢复单击打开，不设置额外的保存排序步骤。
- (decision) 卡片主展示区采用响应式多列卡片网格：随窗口变窄减少列数，但不自动切换为列表；卡片稳定展示名称和最多两行备注，无备注时不保留占位。
- (decision) 选择文件成功后使用居中“保存前确认”模态框，保留首页上下文；模态框包含默认卡片名称、一个或多个用户自建类别选择，以及无类别时创建第一个类别的入口；只有明确保存才创建卡片，取消不留下卡片或临时记录。
- (decision) 保存前确认中的类别选择采用展开式复选列表，已选状态始终可见；列表内提供新建类别，创建成功后立即自动选中。至少选中一个用户自建类别且名称校验通过后才允许保存，未满足时就地解释。
- (decision) 全局名称搜索框常驻在右侧主区域顶部。存在搜索输入时，右侧切换为全部卡片范围的搜索结果，左侧当前类别状态保持不变；清空或退出搜索后返回原当前类别，不跳转到全部卡片。
- (decision) 全局搜索随非空输入实时更新，无需按 Enter；纯空白不进入搜索态；清空按钮或 Esc 退出并恢复原类别。匹配排序按 PRD：完整名称、名称开头、其他包含，同级沿用全部卡片手动顺序。
- (decision) 卡片编辑复用新增确认的居中模态框结构。编辑态提供名称、完整备注、类别和文件关联编辑，并只读展示完整路径，提供复制路径、在文件管理器中显示和重新选择文件；遵循既有校验与数据保持规则。
- (decision) 新增/编辑模态框仅在表单相对初始值存在实际修改时，对关闭、取消或 Esc 提示“继续编辑 / 放弃修改”；无修改直接关闭。新增放弃不留记录，编辑放弃保留原数据。
- (decision) 左侧类别栏标题常驻“＋”用于新建用户类别；每个用户自建类别常驻独立“更多”按钮，菜单提供重命名和删除。全部卡片与未分类不显示类别管理菜单；类别名称区域仅负责切换当前类别。
- (decision) 用户自建类别排序采用显式“整理类别”模式：仅用户类别显示拖动手柄且名称不切换类别；全部卡片固定顶部、未分类固定底部且均不可拖动；调整即时持久化。
- (decision) 删除用户类别使用居中破坏性确认对话框：显示类别名称、类别卡片总数、将进入未分类的卡片数，并明确不会删除卡片或源文件；仅明确点击“删除类别”执行，取消或关闭保持全部状态不变。
- (decision) 若删除的是当前类别，删除成功后统一切换到全部卡片视图，使目标稳定并可立即确认卡片仍被保留。
- (decision) “移出当前类别”仅在用户自建类别视图的卡片更多菜单中显示；卡片只属于当前类别时菜单项保留但禁用，并解释“请先加入其他类别”；全部卡片和未分类视图不显示此操作。
- (decision) 全局删除卡片使用居中破坏性确认对话框：显示卡片名称，明确从所有类别移除但不会删除、移动或修改源文件；仅明确点击“删除卡片”执行，取消或关闭保持全部状态不变。
- (decision) 主打开失败与文件管理器定位失败共用居中错误对话框骨架，标题和说明区分“无法打开文件”与“无法定位文件”，并说明卡片仍保留；提供重新选择文件、删除卡片和关闭。错误框中的删除必须继续进入全局删除确认，不得直接删除。
- (decision) 从失败流程重新关联成功后不自动重试原打开或定位动作；关闭失败流程并返回原首页上下文，以非阻断成功提示说明“已重新关联”；用户再次点击后才触发新的系统操作。
- (decision) 选择的源文件已被其他卡片收录时，使用居中冲突对话框显示“该文件已收录”和原卡片名称，提供查看原卡片、重新选择、取消；查看原卡片进入其编辑模态框，离开当前有未保存修改的表单时遵循既定放弃修改确认。冲突不创建第二张卡片，也不覆盖当前关联。
- (decision) V1 产品自身界面仅使用简体中文，不提供语言切换或双语验收；Windows 与 macOS 的系统文件选择器、安全提示、选择打开方式等原生界面仍跟随操作系统语言。
- (decision) 产品微文案采用冷静、直接、工具化语气：短句说明发生了什么、卡片或源文件是否受影响、下一步可执行动作；避免拟人、夸张、情绪化安慰和无必要的技术术语。
- (decision) V1 采用适用于桌面应用的完整 AA 无障碍基线：参照 WCAG 2.2 AA 适用原则，所有功能可由键盘完成，焦点清晰，状态不只依赖颜色，兼容系统缩放与文字放大，提供读屏语义，并尊重减少动态效果设置。
- (decision) 卡片与类别整理模式同时提供指针拖动手柄和键盘上移/下移按钮；每次键盘移动后保持焦点，并向读屏播报项目名称、当前位置和总数。
- (decision) V1 不设置全局组合快捷键；全部功能通过可见入口以及 Tab、方向键、Enter、Space、Esc 完成，避免与 Windows、macOS 或辅助技术快捷键冲突。
- (event) 已生成四方向并排视觉探索稿 .working/design-directions-4.html；仅供用户选择视觉人格，尚未形成视觉决策。
- (decision) 视觉人格选择 C“结构化索引”：采用高对比线框、方形组件、清晰分隔、高信息密度与可审计秩序感；不照搬示例中的英文或编号装饰，界面继续使用简体中文与冷静直接工具化文案。
- (event) 已基于结构化索引视觉人格生成四套浅色语义配色探索稿 .working/color-themes-4.html；尚未形成配色决策。
- (decision) 浅色配色选择 B“档案绿标”：canvas #F4F3EC，surface #FFFDF7，text #1B211D，text-muted #566158，border #253229，action #1F6248，action-hover #154532，focus #6D43B5，success #216E39，warning #895400，danger #A52A2A。语义 token 优先，Finalize 时逐组件验证 AA 对比度。
- (decision) 字体策略采用平台系统中文无衬线字体承载名称、正文、按钮和说明；数量、顺序位置、只读路径等辅助信息使用系统等宽字体；不依赖网络字体，长备注不使用等宽字体。
- (decision) 卡片仅在全部卡片和全局搜索结果中显示所属类别，最多展示两个类别，更多以“+N”表示；具体用户类别和未分类视图隐藏类别信息。类别标签仅用于识别，不提供点击跳转。
- (decision) 卡片显示小型文件类型图标与扩展名标签，只依据文件名或扩展名呈现，不读取或预览文件内容，不改变打开方式。可执行文件与脚本不增加产品额外警告，保留操作系统安全提示。
- (decision) 不提供紧凑/宽松手动切换，不新增显示偏好或持久化状态。卡片网格采用均衡紧凑密度，仅随窗口宽度自动减少列数，保持同一布局结构。
- (decision) 侧栏新建与重命名类别使用锚定触发位置的浮层，包含单一名称输入、就地校验和保存/取消；处理窗口边缘避让、焦点移入、Esc 关闭，并在关闭后把焦点返回触发按钮。
- (decision) 首次无卡片空状态只突出主行动“选择文件”，并说明应用不会扫描磁盘；侧栏“＋”仍可独立创建类别，但不与主行动并列竞争。选择文件后可在保存前确认中创建并自动选中第一个类别。
- (decision) 界面采用克制功能动效，仅用于焦点、悬停、浮层出现与排序位置变化，时间短且无装饰性；系统启用减少动态效果时取消非必要过渡，以即时状态变化保留完整反馈。
- (decision) Windows 与 macOS 采用统一产品界面：应用内信息架构、组件行为与视觉令牌一致；系统文件选择器、资源管理器或 Finder、选择打开方式、安全提示和窗口控制遵循各平台原生规范。
- (decision) 桌面窗口常规设计基线为 1024×720，最小约 760×560；窗口可向更大尺寸自由调整，不设 UX 最大宽度。固定侧栏宽度保持稳定，主区域随可用宽度自动增加或减少卡片列数，最窄保持一列，不切换布局结构。
- (decision) 保存前确认中的类别始终不预选；无论从全部卡片、用户类别或未分类发起，用户都必须明确勾选一个或多个用户自建类别，以降低误归类风险。
- (decision) 新增卡片保存成功后，若当前视图能够展示新卡片，则保持原视图；若当前视图无法展示新卡片，则切换到全部卡片，使新卡片立即可见且避免不必要跳转。
- (decision) 在用户类别中编辑卡片并取消当前类别关系、同时保留其他类别后，保存成功仍停留当前类别；卡片从当前网格消失，并以非阻断状态提示“已移出当前类别”；其他类别中的卡片及顺序不受影响。
- (decision) 用户自建类别无卡片时显示明确类别空状态，主行动为选择文件，次要入口为查看全部卡片；不新增批量选择或批量归类能力。
- (decision) 非阻断成功反馈统一使用主区域底部状态条：短时显示、可手动关闭、礼貌级读屏播报，不遮挡卡片或操作按钮，也不推动主布局。
