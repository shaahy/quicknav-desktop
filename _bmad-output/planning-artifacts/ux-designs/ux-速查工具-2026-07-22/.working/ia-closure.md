## 外部系统交互

| ID | 系统交互 | 产品边界 |
|---|---|---|
| X01 | 系统文件选择器 | 单文件选择；取消不创建或改变记录 |
| X02 | 系统选择打开方式 | 没有默认关联应用时由系统承载 |
| X03 | Windows 资源管理器 / macOS Finder | 定位源文件；失败回到 S17 |
| X04 | 操作系统安全提示 | 产品不得绕过或屏蔽 |

## 旅程闭环

- **UJ-1 首次建立导航库：** S05 → X01 → S10（必要时 S12）→ S01/S02；Climax 为明确保存后新卡片立即可见。
- **UJ-2 日常快速打开：** S01/S02/S03 或 S04 → 卡片主打开 → X02 或系统默认应用；Climax 为两次核心操作内把文件交给系统。
- **UJ-3 整理同一张卡片：** S11、S08、S09、S13/S14 → S01/S02/S03；Climax 为单一类别关系与当前视图顺序变化不影响其他视图。
- **UJ-4 修复失败入口：** S16/S17 → X01 → 成功状态条 → S01/S02/S03；Climax 为重新关联后保留名称、备注、类别关系和各视图顺序，且不自动重试系统动作。

## Closure 结论

- 每项已确认需求均有 Surface 或系统交互承载。
- 每个产品内 Surface 均能落入至少一条 PRD 旅程。
- 不新增独立类别管理页或卡片详情页。
- 系统文件选择器、打开方式、文件管理器与安全提示不伪装为产品内页面。
