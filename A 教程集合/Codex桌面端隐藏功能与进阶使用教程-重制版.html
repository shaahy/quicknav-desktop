RECOMMENDED DEFAULTS

适合你的推荐设置

这是面向本地 Windows OPC/DRI 的起步建议，不是强制配置。受工作区管理员策略约束的选项，以实际界面为准。

设置推荐为什么
Prevent sleep while running开启本地长任务时避免电脑休眠中断。
Follow-up behavior先使用排队新手不容易用补充消息意外改变正在执行的步骤；熟练后再使用实时 steering。
PersonalityPragmatic 或 None复杂工作更重视结论、依据和边界；核心规则仍写入自定义指令。
Custom instructions保留稳定个人偏好称呼、沟通原则、审批门适合全局；具体项目规则放项目 AGENTS.md。
Enable local memories开启后观察减少重复交代，但不要把它当唯一规则来源；敏感任务用任务级控制关闭贡献。
工具辅助聊天生成记忆谨慎开启可能将使用 MCP 或网页搜索的聊天纳入记忆输入；涉及私有系统时更应审慎。
Browser website accessAlways ask按站点授权，减少误进不可信页面。
Browser Developer mode按需开启调试网页价值很高，但完整 CDP 可见更多浏览器内部信息。
默认权限Workspace write + 按需审批足以完成多数本地任务，同时限制工作区外、网络和敏感动作。
Scheduled 本地修改优先 Worktree避免后台任务直接碰正在编辑的主工作区。
