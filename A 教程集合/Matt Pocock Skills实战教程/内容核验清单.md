# Matt Pocock Skills 内容核验清单

核验日期：2026-07-20

仓库版本：`1.1.0`（以核验时 `package.json` 为准）

## 口径

- **官方事实**：技能名称、调用方式、流程、输入与产物，来自官方 README 和对应 `SKILL.md`。
- **教程判断**：重叠对象、冲突等级与采用建议，是结合本机 gstack、Superpowers 现状形成的决策建议，不代表仓库作者立场。
- **用户调用**：frontmatter 含 `disable-model-invocation: true`，只有用户显式选择时启动。
- **模型调用**：未禁用模型调用，可被任务描述触发，也可被其他技能调用。

## 安装与配置结论

1. `npx skills@latest add mattpocock/skills` 支持选择目标 Agent 与具体技能。
2. skills.sh 的官方表述是把技能复制进项目，适合项目级、可编辑安装。
3. 若安装器允许选择用户级 Codex 目录，技能本体可以跨项目复用。
4. `setup-matt-pocock-skills` 官方明确是 per-repo 配置，工程技能首次使用前运行一次。
5. Setup 会读取并可能修改 `AGENTS.md` 或 `CLAUDE.md`，并创建 `docs/agents/*.md`；这可能与现有路由规则和单一事实源发生冲突，必须审阅后再写入。

## 最小试用建议

- **建议先试**：`prototype`、`domain-modeling`、`codebase-design`、`teach`。
- **按需启用**：`triage`、`improve-codebase-architecture`、`research`、`resolving-merge-conflicts`、`handoff`、`writing-great-skills`。
