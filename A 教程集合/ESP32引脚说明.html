02 / BOOT

🚦 使能、复位与启动

决定芯片何时开始运行，以及上电时采用什么配置。

脚号名称名称拆解／为什么这样叫实际作用
4CHIP_PUCHIP＝芯片；PU 按 Power Up（上电使能）理解。高电平使能，拉低复位／禁用。它是控制信号，不是电源输入，不能悬空。

52GPIO46GPIO＝General-Purpose Input/Output，通用输入输出；46 是 GPIO 编号，不是封装脚号。参与启动模式与启动日志等配置。

Strapping Pins（启动配置引脚）：芯片在复位启动时读取这些引脚的电平。启动后，它们可以按允许的方式承担其他任务，但外接电路不能干扰启动条件。

名称含义与芯片的关系
BOOT启动常用于选择下载等启动模式，不等于复位。
RESET / RST复位让芯片重新开始运行。
ENEnable，使能模组或开发板常用它标注使能信号。

53XTAL_NXTAL＝晶振；N＝Negative，负端标识。连接 40MHz 主晶振的另一端。N 不表示接地。
54XTAL_PXTAL 是 Crystal（晶体／晶振）的惯用简写；P＝Positive，正端标识。连接 40MHz 主晶振的一端。P 不表示接电源。
XTAL 是 Crystal 的惯用简写。主晶振为 40MHz，不代表 CPU 只能运行在 40MHz。P／N 是端点标识，不是电源／地。参考图没有安装外部低频晶振，相关端口按 GPIO15、16 引出。

05 / MEMORY

💾 存储器通信

Flash 保存固件，PSRAM 提供额外运行内存。片选、时钟和数据线共同完成通信。

SPI＝Serial Peripheral Interface（串行外设接口）。后缀说明信号职责。Flash 断电保留数据；PSRAM＝Pseudo Static RAM（伪静态随机存取存储器），作为运行工作空间，断电后数据丢失。

脚号名称名称拆解／为什么这样叫实际作用
28SPICS1SPI＋CS（Chip Select，片选）＋编号 1。在参考图中选择 PSRAM 扩展内存。
30SPIHDSPI＋HD，对应 Hold（保持／暂停）信号。传统功能为暂停通信；四线 SPI 模式下兼作数据线。
31SPIWPSPI＋WP（Write Protect，写保护）。传统功能为写保护；四线 SPI 模式下兼作数据线。
32SPICS0SPI＋CS（Chip Select，片选）＋编号 0。在参考图中选择 Flash 存储器。
33SPICLKSPI＋CLK（Clock，时钟）。为存储器通信提供时钟节拍。
34SPIQSPI 的 Q 数据信号，传统上对应存储器输出方向，不强行扩展 Q。传统单线模式为主控接收方向；多线模式参与双向数据传输。
35SPIDSPI 的 D 数据信号，是沿用的数据端名称，不强行扩展成英文缩写。传统单线模式为主控发送方向；多线模式参与双向数据传输。
36SPICLK_NSPI＋CLK（Clock，时钟）＋N（Negative，负端标识）。复用信号名；参考图按 GPIO48 引出，不代表正在输出 SPI 时钟。
37SPICLK_PSPI＋CLK（Clock，时钟）＋P（Positive，正端标识）。复用信号名；参考图按 GPIO47 引出，不代表正在输出 SPI 时钟。
CS：本次找谁？ → CLK：什么节奏？ → D / Q：传什么？
名称保留了传统功能，实际作用随模式变化：WP／HD 在四线模式下也传输数据。GPIO26～32 通常已供存储器使用；八线存储器还可能占用 GPIO33～37。SPICLK_P／N 在参考图中按 GPIO47／48 引出，不代表正在输出 SPI 时钟。
06 / GPIO

🔌 通用输入输出与通信

GPIO 是可以配置用途的信号端，外设控制器决定信号按什么规则工作。

GPIO4＝
General-Purpose通用用途
＋
Input / Output输入／输出
＋
4GPIO 编号

GPIO4 对应裸芯片的 第 9 脚。数字 4 不表示封装脚号，也不指定接什么器件。输入用于读按钮等信号；输出用于控制电平。GPIO 不能直接代替电机或喇叭的功率驱动。

UART：串行收发

UART＝Universal Asynchronous Receiver/Transmitter（通用异步收发器）。发送和接收方向以 ESP32-S3 为参照。

脚号名称名称拆解／为什么这样叫实际作用
49U0TXDU0＝UART0；TX＝Transmit，发送；D＝Data，数据。UART0 发送数据，对应 GPIO43。发送方向以 ESP32-S3 为参照。
50U0RXDU0＝UART0；RX＝Receive，接收；D＝Data，数据。UART0 接收数据，对应 GPIO44。接收方向以 ESP32-S3 为参照。

JTAG：检查程序如何运行

JTAG＝Joint Test Action Group（联合测试行动小组），后来用于称呼相关测试、调试接口。信号前缀 M 保留原名，所引用官方接口说明没有解释其展开，不擅自写成 Master。

脚号名称名称拆解／为什么这样叫实际作用
44MTCKTCK＝Test Clock，测试时钟；前缀 M 不作未经证实的展开。JTAG 调试时钟，对应 GPIO39。
45MTDOTDO＝Test Data Out，测试数据输出；前缀 M 保留原名。向调试器输出数据，对应 GPIO40。
47MTDITDI＝Test Data In，测试数据输入；前缀 M 保留原名。接收调试器数据，对应 GPIO41。
48MTMSTMS＝Test Mode Select，测试模式选择；前缀 M 保留原名。控制 JTAG 状态机，对应 GPIO42。

USB、ADC 与触摸

脚号名称名称拆解／为什么这样叫实际作用
25 / GPIO19USB_D−USB＝Universal Serial Bus，通用串行总线；D＝Data，−＝差分负端。USB 数据对的一根，不是地线。
26 / GPIO20USB_D+D＝Data，+＝差分正端。USB 数据对的另一根，不是正电源。
GPIO1～20ADCAnalog-to-Digital Converter，模数转换器。把模拟电压转换为数字读数；GPIO1～10 属 ADC1，11～20 属 ADC2。
GPIO1～14Touch触摸感应。可用于电容触摸，需配合电极及配置。

USB 通过两根数据线的电压差传信号。使用 GPIO19／20 的 USB 功能时，不能随意把它们改作其他用途。ESP32-S3 的 GPIO 编号为 0～21、26～48，没有 GPIO22～25。

I²C、I²S 与 PWM：为什么图上没有固定专用脚？

许多外设信号可以通过内部 GPIO Matrix（GPIO 信号矩阵）和 IO MUX（输入输出复用）分配到合适的 GPIO。具体用途由软件配置、芯片限制与实际接线共同决定。
